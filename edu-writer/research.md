# Research mode

Extra rules for research tasks, applied on top of the base standard in SKILL.md. Activate only when /edu-writer is invoked with research.

## Sources

- Cite only sources with a named author and a publication date.
- Prefer sources with a DOI, and give the DOI as a URL in the reference.
- Search for the most recent work first: start with the current year, then step back one year at a time until valid sources are found.
- Before searching, ask the user how many sources are needed: a number, a range, or no limit. If the request does not state a count, reply with that question only and wait for the answer.
